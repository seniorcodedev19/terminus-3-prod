Companion to the Quality Panel Judge Guide.

These are synthetic composites. They are not a dump of any submitted task. Snippets use generic paths and names so you can match a panel finding to a shape, then apply the fix in your own files.

Minor and Major both block. The label describes reachability and impact, not whether you must fix it.

Entries are grouped by which file carries the defect:

A — the contract (instruction.md, referenced docs): A-1, A-2, A-3
B — the reference solution (solution/): B-1, B-2, B-3
C — the verifier and environment (tests/, task.toml, Dockerfiles): C-1–C-11
A — Contract
A-1 — Broken render in Required outputs
Example 1-B · coherent_contract · Major (category 5)

What the candidate was told:

markdown

Copy
## Required outputs

When you are done, leave the following files at these exact paths:

- `/app/tool'`
- `/app/'error_codes': ['internal.test.id']}`
Why it's bad. One path has a stray quote. The other is a Python repr() fragment where a path should be. Neither is a deliverable the verifier can grade.

Fix. Read the rendered instruction.md. The list should name exactly the artifacts your tests check. Fix the generation step so template leftovers cannot recur.

Why it's bad. The contract tells the candidate to create a path the verifier uses as a nonexistent-file probe. If the candidate obeys, the misuse test breaks. The plausible paths may also be unenforced.

A-3 — An edge the contract allows but never defines
Example 1-A · coherent_contract · Minor (category 4)

What the candidate was told:

markdown

Copy
A group whose records are all deleted is not a group of the output at all.

| `min_time`, `max_time` | Earliest and latest surviving record. |
Why it's bad. One reading excludes deleted groups from the aggregate. Another still counts their timestamps. Both are defensible; the golden encodes only one.

Fix. State the edge in the same place it is introduced: for example, "records of such a group do not contribute to min_time or max_time."

B — Reference solution
B-1 — Documented field width, copied through unpadded
Example 2-A · correct_reference_solution · Major

What the candidate was told: field 14 is eleven digits.

What the reference does: writes the source string unchanged. Every source row is ten digits, so every golden row is ten digits. A candidate who pads to eleven as documented fails the golden.

Fix. Pad at write time, regenerate goldens, and assert len(field) == N on real output bytes.

B-2 — Minimum significant digits lost to the format string
Example 2-B · correct_reference_solution · Minor

What the candidate was told: write at least twelve significant digits.

What the reference does: printf("%.12g", v). 1.5 prints as 1.5.

Why it's Minor. Numeric tolerance may still match; the display contract is still violated.

Fix. Use a format that guarantees the count (%.12e or fixed precision). Do not use %g for a minimum-digit rule.

B-3 — Loop-carried state refreshed on only one branch
Example 2-C · correct_reference_solution · Major

Pattern: A timestamp meaning "when did this entity leave the region it is currently bound to" is updated when the bound region changes, but is only reset on one later branch. The next iteration measures elapsed time from the stale departure.

Fix. Whenever the bound region changes, recompute the timestamp. Add a fixture that walks A → B → C and asserts the third step by hand.

C — Verifier and environment
C-1 — Privileged read of a candidate-written path, no symlink guard
Example 3-B · protected_ground_truth · Major · symlink_deref

How the candidate is run: unprivileged UID writes /app/out/result.json.

What the verifier does, as root:

python

Copy
with open(res["path"], encoding="utf-8") as fh:  # follows symlinks
    text = fh.read()
Where goldens live: COPY expected /tests/expected with chmod 0700 /tests/expected.

Why it's bad. The unprivileged process cannot read the golden, but it can write a symlink at the output path. Root open() follows it and grades the golden against itself.

Fix. Guard this read (O_NOFOLLOW plus is_symlink()). A check on some other copy step does not count.

Separate mode keeps /tests/expected out of the agent container. It does not hide it from this privileged read of a candidate-controlled path.

C-2 — Same mechanism, unguessable golden root: why this is Minor
Example 3-A · protected_ground_truth · Minor · symlink_deref

Same unguarded read_text() on the candidate's declared output. Goldens sit at /tests/expected/... in a separate verifier image. The string /tests/expected appears nowhere in instruction.md or environment/.

Reachability: (1) The symlink is on a declared artifact path, so it can reach grading. (2) The target is not named or derivable from candidate-visible material — a guess at convention is not a derivation. (3) No independent recompute defeats the join.

Fix. Identical to C-1. The label is Minor; the task still comes back.

C-3 — A privilege drop a setuid binary can undo
Example 3-C · protected_ground_truth · Major · chmod_follow

python

Copy
DROP = ["setpriv", "--reuid=12000", "--regid=12000", "--clear-groups"]
# no --no-new-privs
subprocess.run(DROP + [str(binary), str(staged)])
The agent image has no USER, so the solve session can mark a binary 4755 and root-owned. After the UID drop, exec of that binary regains root.

Fix. Add --no-new-privs, or nosuid, or strip setuid before exec. A static check greps some setpriv spellings; a different drop with the same hole still needs this thinking.

C-5 — Test identity leaked through the test's own name

C-6 — Test identity leaked through the fixture directory
Example 3-I · protected_ground_truth · Major · label_from_basename

Reject fixtures live under tests/fixtures/invalid/. The candidate binary receives that full path as argv[1].

Fix. Stage each fixture into a neutrally named temp file before exec, or flatten accept/reject into one directory and keep the expected outcome in a manifest the candidate never sees.

C-7 — A persisted directory that is only partially reset
Example 3-J · protected_ground_truth · Major

artifacts = ["/app/work/"]. The verifier rebuilds one binary inside that tree and leaves everything else.

Why it's bad. Candidate code can leave /app/work/cache.json at solve time and read it after rebuild.

Fix. Enumerate what you intend to keep and delete the rest, or copy source to a verifier-owned directory and never execute from the persisted tree.

C-8 — Oracle binary copied into the candidate's build workspace
Example 3-L · protected_ground_truth · Major — and Example 4-B · sound_verifier · Major

The contract offers a reference binary for inspection. The verifier copies the whole /app tree — oracle included — into the workspace where candidate code is built and run.

Why it's bad. Candidate code can exec the oracle and re-emit its output. "Keep unchanged" is a request, not containment.

Fix. Exclude the oracle from the staged workspace and confirm the running binary cannot reach the original path either.

C-9 — Candidate binary left writable by its own UID
Example 3-M · protected_ground_truth · Minor

The contract promises a fresh process per cycle. The verifier compiles as the same UID it later execs, then chmod 0755 so the process can rewrite itself.

Fix. chmod 0555 (or compile as a different UID). If the contract is stateless, every path that process can reach must be non-writable to it.

C-10 — A test that asserts the opposite of the contract
Example 4-C · sound_verifier · Major

Contract: reuse a cache entry when rerunning the action would write the same bytes.

Test: append a comment-only edit, observe identical artifacts, and assert the generator ran anyway.

Why it's bad. The suite enforces source-byte fingerprinting, which is the failure the contract forbids.

Fix. Make the test and the contract agree. If the promise is output-based, a comment-only edit must hit the cache. Before shipping, reverse each documented promise and confirm the matching test fails.

C-11 — A restriction stated in prose and enforced nowhere
Example 4-E · sound_verifier · Minor

Contract: use only the language's standard library.

Verifier image: installs another interpreter and does not restrict exec.

A wrapper that shells out to that interpreter still "uses the standard library." Honest solutions do not stumble into this; the restriction is still unenforced.

Fix. Enforce it mechanically (stripped PATH, no extra interpreters, import/exec scan) or remove the sentence from the contract.
